# Tracklist box userscripts

The userscripts whose only job is the [Tracklist box](../shared/tracklist_editor/): they read
the tracklist off a site's page and put it back as MixesDB wiki syntax, nothing more. They are
separate scripts, installed separately – this folder just keeps them together, away from the
scripts that also bring a Page Creator, a toolkit and the rest.

## The scripts

Each folder holds one userscript and a README describing its features.

| Script | Runs on | What it does |
| --- | --- | --- |
| [NTS](NTS/) | nts.live | Tracklist in wiki syntax |
| [BBC](BBC/) | bbc.co.uk | Tracklist in wiki syntax |
| [The Lot Radio](TheLotRadio/) | thelotradio.com | Tracklist in wiki syntax |
| [radioeins](radioeins/) | radioeins.de | Tracklist in wiki syntax |
| [True Underground](True_Underground/) | trueunderground.one | Tracklist in wiki syntax, right click and copying re-enabled |
| [Discogs](Discogs/) | discogs.com | Release tracklist in wiki syntax, file details |
